    👁️ Visitor Tracking

    ⚠️ GitHub Pages ek static hosting hai — isme koi server/backend nahi hota, isliye kisi bhi tool se real visitor IP address, unki visit history, ya IP block/unblock karna GitHub Pages par technically possible nahi hai (GitHub khud bhi ye data nahi deta).

    Agar tumhe real visitor analytics (kitni baar dekha, kahan se aaye) chahiye to website me ek free analytics service (jaise Cloudflare Web Analytics ya Google Analytics) ka script add karna padega — wo apna dashboard alag se dega. Blocking ke liye Cloudflare jaisi service ko domain ke aage lagana padta hai.
